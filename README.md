# 🤖 AI-Powered Trend Detection Agent

## 📋 Project Overview

An intelligent AI agent that automatically identifies, ranks, and summarizes trending topics from online textual content using Natural Language Processing (NLP), Machine Learning, and Large Language Models.

### Key Features

- **Topic Extraction**: LDA and NMF topic modeling
- **Trend Ranking**: Multi-factor scoring (Frequency 50% + Growth 30% + Recency 20%)
- **Sentiment Analysis**: VADER + TextBlob dual analysis
- **AI Summarization**: Template-based and LLM-powered summaries
- **Interactive Dashboard**: Streamlit-based web interface
